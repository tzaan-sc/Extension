# OmniLoader - All-in-One Media & Document Downloader

Extension đa năng hỗ trợ bắt link và tải về video (YouTube, phim m3u8 HLS, TikTok, Facebook), tài liệu học tập (Scribd, Studocu, Canvas) và album ảnh chất lượng cao.

---

## 🚀 Hướng dẫn cài đặt trên Microsoft Edge

1. Mở trình duyệt **Microsoft Edge**, truy cập vào địa chỉ:
   ```text
   edge://extensions
   ```
2. Bật công tắc **Chế độ dành cho nhà phát triển (Developer mode)** ở góc dưới bên trái thanh menu.
3. Nhấn vào nút **Tải phần mở rộng chưa được giải nén (Load unpacked)** ở góc trên cùng.
4. Chọn thư mục:
   ```text
   D:\GIT\Extension\Download
   ```
5. Extension **OmniLoader** sẽ xuất hiện trên thanh công cụ của Edge. Bạn có thể ghim (Pin) icon lên thanh địa chỉ để tiện sử dụng!

---

## 🌟 Các tính năng chính

- 🎬 **Tải Video YouTube:** Tự động bắt link các định dạng 1080p, 720p, 360p, file âm thanh M4A và phụ đề VTT.
- ⚡ **Tải phim luồng HLS (.m3u8):** Tự động bắt link m3u8, tải song song nhiều chunk `.ts` và ghép thành file `.mp4` hoàn chỉnh trực tiếp trong trình duyệt.
- 📚 **Cào tài liệu học tập sang PDF:** Tự động quét thẻ `<canvas>` trên các web học liệu chặn tải (Scribd, Studocu, Canvas) và xuất ra file tài liệu.
- 🖼️ **Tải Album ảnh:** Quét toàn bộ ảnh chất lượng cao trên trang và tải về hàng loạt.
- 🎨 **Giao diện Glassmorphism Dark Mode:** Đẹp mắt, mượt mà, phân loại theo tab (Tất cả, Video, Âm thanh, Tài liệu, Ảnh).
